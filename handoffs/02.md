# Handoff 02: Rescale world and shark parameters

## Built
Constants in `fishes.cpp` set to the values in R1–R3:
- `METERS_PER_PIXEL` 0.02 → world 30 × 16 m (`WORLD_WIDTH`/`WORLD_HEIGHT` derive from it).
- `N_FISH` 4000.
- `SHARK_LENGTH` 3.0 (flows into `SHARK_BODY.length`).
- `SHARK_MOTION`: `v_min` 0.5, `v_cruise` 1.0, `v_max` 2.5, `r_max` 0.8, `T_v` 1.0, `T_r` 0.4. `K_phi` 4.0 and `tau` 0.3 unchanged.
- `SHARK_SIGHT_RANGE` 6.0, `SHARK_COMFORT_RANGE` 4.0, `SHARK_EAT_DISTANCE` 0.3.

Unchanged: fish parameters, `SHARK_HUNGER_RATE`, `SHARK_EAT_DURATION`, the 45° rule, `WALL_BUFFER_DIST`, `SPAWN_MARGIN`, `GRID_CELL_SIZE`.

## Interfaces provided
None. Constants only.

## Deviations
None.

## Not verified
- No unit test for the constants. The spec treats R1–R3 as a build check, and the constants are private to `fishes.cpp`.
- Visual check was a ~14 s run with screenshots. Fish school and two ~150 px spines move among them. No eating event was observed. Shark wall behaviour at the new speeds was not watched (deferred to issue 06).
- Frame rate with 4000 fish was not measured.
