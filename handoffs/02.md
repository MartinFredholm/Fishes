# Handoff 02: Shark separation from the body line

## Built
- In `desiredSharkAcceleration` (`fishes.cpp`), the separation term now measures from the shark's own nose (`self.kin.pos`) to `nearestPointOnBodyLine(self.kin.pos, sharks[j].body.body_line)`. Before, it measured to the other shark's nose. `SHARK_COMFORT_RANGE`, the ramp and `W_SEPARATION` are unchanged, and the term is still not normalised.
- The function receives `sharks_old`, so it reads the previous frame's body line. Fish fleeing reads the same one.
- Eating, targeting and the safety filter are untouched.

## Interfaces provided
None new. Uses `nearestPointOnBodyLine` and `SharkBody::body_line` from issue 01.
