# Handoff 01: Body line and fish fleeing

## Built
- `SharkBody::body_line` is set in `seedSharkBody` and `updateSharkBody`. It is built from the nose path before the body wave is applied, so it does not depend on the wave.
- The spine and the body line share one placement function, `placeAtUniformS(path, count, length)`, in the anonymous namespace of `shark_body.cpp`. It was `placeSpine(path, params)`, and it now takes a point count so both can use it. There is still one path walk.
- `nearestPointOnBodyLine` is a brute-force scan over all segments that clamps each projection to its segment. A zero-length segment gives its start point.
- In `desiredFishAcceleration` (`fishes.cpp`), the flee term measures from the nearest body-line point instead of `s.kin.pos`. The range, ramp, normalisation and weight are unchanged.
- Tests are in `tests/body_line_tests.cpp`, in the suites "body line" (R1–R5) and "nearest point on body line" (R6–R8).

## Interfaces provided
- `constexpr int BODY_LINE_POINTS = 5;` in `shark_body.h`.
- `std::vector<Vector2> SharkBody::body_line`: world meters, y down, `BODY_LINE_POINTS` points, from the nose (index 0, s = 0) to the tail tip (s = 1).
- `Vector2 nearestPointOnBodyLine(Vector2 p, const std::vector<Vector2> &body_line);` in `shark_body.h`. It expects at least one point.

All three match the planned interfaces.
