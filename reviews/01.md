### Non-blocking notes
- `pointAtAnyArc` (`shark_body.cpp:107`) repeats the interpolation in `pointAtArc`. The name "Any" does not say how the two differ (a binary search vs a search cursor). A name like `pointAtArcSearched`, or one shared lerp helper, would be clearer.
- `FIRST_FLEXIBLE_NODE = 9` in the tests is a hard-coded number. Deriving it from 0.35 and `NODES` (`ceil(0.35 · 23)`) would keep it right if the stiff length is tuned again.
- `pathCurvatureAtNodes` returns all 24 values, but `stiffenFront` uses only nodes 1–9. That fits the interface the issue asks for (issue 02 uses it), so it is not speculative.
- `std::clamp(arc, lowest, highest)` is undefined if the path is shorter than two segments. That cannot happen while the path keeps at least L, so this is not a bug today.
- The spec's 13 cm and 25 cm are the nose's straight-line distance from `kin.pos`. The lateral part is 12 and 20 cm. The spec text is correct, but it could say "distance".
